Foundation

BlueRise Workforce design system

Tokens and component patterns shared by the public website, the Portal, and the Admin application. Everything on this page renders from packages/ui — the same stylesheet those surfaces consume, not a copy.

Colour

A single blue ramp, a neutral ramp warmed slightly toward blue, and four semantic hues. Components reference semantic aliases such as --br-color-primary , never a ramp step directly, so a surface can be re-themed without touching a component.

Typography

Inter with a system fallback, on a fluid scale built with clamp() so headings shrink on small screens without a cascade of breakpoint overrides. Body copy never drops below 16px, and line length is capped near 68 characters.

@for (item of typeScale; track item.token) {
{{ item.label }} {{ item.token }} Stronger workforces
}

Spacing, radius, and elevation

A 4px spacing base, six radii, and four low-contrast shadow levels. Heavy drop shadows read as dated, so elevation stays subtle.

Buttons

Every button clears a 44×44 pixel target, keeps a visible focus ring, and states its disabled reason through aria-disabled rather than disappearing.

Forms

Badges and alerts

Status is never carried by colour alone. Every badge and alert pairs its hue with a word, and alerts pair it with an icon too.
